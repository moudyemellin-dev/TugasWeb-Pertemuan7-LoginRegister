# Tugas Web Pertemuan 7 - Login Register PHP

Repository ini berisi Tugas Rutin Pertemuan 7 mata kuliah Pemrograman Web.

## Deskripsi

Aplikasi Login/Register sederhana menggunakan PHP Native dengan file JSON sebagai penyimpanan data.

## Fitur

- Registrasi akun
- Validasi nama, email, dan password
- Validasi email menggunakan `filter_var()`
- Password disimpan menggunakan `password_hash()`
- Data user disimpan ke `users.json`
- Pengecekan email duplikat
- Login menggunakan Session
- Dashboard terproteksi
- Logout menggunakan `session_destroy()`
- Sanitasi input menggunakan `htmlspecialchars()`
- Pesan error dan sukses
- Remember Me menggunakan Cookies
- Edit Profile
- Tampilan responsive dengan CSS

## Teknologi

- HTML5
- CSS3
- PHP Native
- JSON
- Session
- Cookies

## Menjalankan Project

Simpan folder project di:

`C:\xampp\htdocs\TugasWeb-Pertemuan7-LoginRegister`

Jalankan Apache melalui XAMPP, kemudian buka:

`http://localhost/TugasWeb-Pertemuan7-LoginRegister/`
